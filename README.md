# PNMI-VTA

Code associated with:

**Prenatal Maternal Inflammation Is Associated with Altered Offspring Mesolimbic White Matter Circuitry Observed in Late Midlife**

Preprint: https://www.biorxiv.org/content/10.64898/2026.04.06.716489v1

## Data availability

The data used in this study are not publicly available. Researchers interested in obtaining access to the data should contact the Child Health and Development Studies (CHDS) to inquire about data access procedures.

## Code

This repository contains code used for diffusion MRI processing, tractography, NODDI modeling, tract cleaning, nodewise microstructural extraction, and statistical analyses associated with the study.
